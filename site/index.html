      Sobre o Buscador de CEP

      Consulta de endereços a partir do CEP — e o caminho inverso — usando os dados públicos do ViaCEP.

      Como funciona

      O navegador consulta diretamente a API pública do ViaCEP:

      • viacep.com.br/ws/CEP/json/ — CEP → endereço
      • viacep.com.br/ws/UF/CIDADE/RUA/json/ — endereço → CEP

      Não há servidor próprio: as consultas saem do seu navegador e voltam para a tela.

      Privacidade

      • Nada é enviado para servidores da EstevesTec — o site é estático.
      • O histórico fica salvo apenas no seu navegador (localStorage).
      • O mapa só carrega o Google Maps quando você toca em "Ver mapa aqui".

      Offline

      Instalado como aplicativo, o app abre sem internet, mas as consultas precisam de conexão, porque dependem do ViaCEP.
